# Asset Borrowing System

A Flutter mobile application developed as an asset borrowing system project, focusing on user authentication interfaces, form validation, and application navigation.

## Project Overview

This project demonstrates the development of a mobile application using Flutter and Dart.

The application includes user login and registration interfaces with input validation, password handling, and navigation between screens.

## Features

- User Login Interface
- User Registration Interface
- Form Validation
- Email Validation
- Password Confirmation
- Password Visibility Toggle
- Phone Number Input
- Country Code Selection
- Navigation Between Login and Registration Screens
- User Feedback Using Snackbar and Dialog

## Technologies

- Flutter
- Dart
- Material Design
- Git
- GitHub

## Application Structure

The application currently includes:

### Login Screen

- Username input
- Password input
- Password visibility control
- Form validation
- Login feedback
- Navigation to registration

### Registration Screen

- First name and last name input
- Username input
- Email validation
- Password and confirm password
- Phone number input
- Country code selection
- Registration validation
- Success dialog
- Navigation back to login
